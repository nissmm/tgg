# HR-бот

Бот на aiogram 3 для приёма HR-заявок и уведомлений в топик канала/группы.

## Структура проекта

```
.
├── .env                 # реальные секреты (не коммитить)
├── .env.example         # шаблон без секретов
├── .gitignore
├── requirements.txt
├── main.py              # точка входа
├── config.py            # загрузка переменных окружения
├── storage.py           # хранение данных в бинарных (pickle) файлах в data/
├── filters.py           # проверка "админ канала" / "роль HR"
├── states.py            # состояния FSM
├── keyboards.py         # inline-клавиатуры
├── data/                # создаётся и заполняется автоматически
└── handlers/
    ├── common.py         # /start, главное меню, отмена
    ├── admin.py          # админ-панель
    ├── hr.py              # функционал HR
    └── topics_listener.py # обнаружение топиков форума
```

## Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

`.env` уже заполнен вашими данными (токен бота и id канала). Если понадобится
развернуть бота с другими данными — используйте `.env.example` как шаблон.

## Запуск

```bash
python main.py
```

## Как это работает

**Права.** Админ-панель доступна тем, кто является администратором/создателем
целевого канала-группы (проверяется через Bot API `get_chat_member` — сам бот
должен быть там администратором). Роль **HR** выдаётся отдельно, через
админ-панель, и не связана с правами в Telegram.

**Выбор топика.** Telegram Bot API не предоставляет метод, который вернул бы
список всех топиков форума заранее — это ограничение самого API, обойти его
нельзя. Поэтому бот запоминает топик, как только видит в нём любое сообщение
(или служебное сообщение о создании топика). После того как в нужном топике
кто-то напишет хотя бы одно сообщение, он появится в списке в админ-панели
(«📌 Выбрать топик для уведомлений»).

**Назначение/снятие роли HR.** В админ-панели соответствующая кнопка выводит
список пользователей, писавших боту `/start` (юзернейм и id в формате
`` `123456789` `` — тег моноширинного текста в Telegram, по нему можно
нажать, чтобы скопировать id), после чего бот запрашивает id для назначения
или снятия роли.

**Таблица записей HR.** Кнопка «📊 Таблица записей HR» показывает записи в
виде моноширинной таблицы с фильтрами: все записи / за сегодня / за неделю /
за месяц.

**Функционал HR.** Кнопка «➕ Записать нового кандидата» запускает
пошаговый опрос с проверкой ввода:
1. Кто записал
2. Кого и сколько лет
3. Номер телефона (формат `+79991234567`)
4. Юз (формат `@username`)
5. Дата собеса (формат `ДД.ММ.ГГГГ`)

После заполнения запись сохраняется в `data/hr_records.pkl` и отправляется
сообщением в выбранный топик канала.

## Хранение данных

Все данные лежат в папке `data/` в виде pickle-файлов:
- `users.pkl` — все, кто писал `/start`
- `hr_roles.pkl` — id пользователей с ролью HR
- `hr_records.pkl` — записи HR
- `settings.pkl` — выбранный топик для уведомлений
- `topics.pkl` — обнаруженные топики

Папка и файлы создаются автоматически при первом запуске/записи, вручную
ничего готовить не нужно. `data/` и `.env` исключены из git через
`.gitignore`.
